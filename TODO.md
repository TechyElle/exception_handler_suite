Activity 6 - Exception Handling in Python
===================================

Slide 21: Create a Simple App Calculator

Requirements:
1. Ask user to choose one of four math operations
2. Ask user for two numbers
3. Display the result
4. Ask if user wants to try again
5. If yes, repeat Step 1. If no, display Thank you and exit
6. Use Python Functions and appropriate Exceptions

Coding Standard:
- OOP: Classes, inheritance, encapsulation, abstraction
- snake_case for files/variables/methods, PascalCase for classes
- PEP-8 compliant

Implementation Plan:
1. calculator_base.py - Abstract base class
2. math_operation.py - Base class for operations
3. addition_operation.py
4. subtraction_operation.py
5. multiplication_operation.py
6. division_operation.py
7. calculator_app.py - Menu system
8. main.py - Entry point
